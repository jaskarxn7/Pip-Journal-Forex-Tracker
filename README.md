# Pip-Journal-Forex-Tracker
Forex Backtest &amp; Analytics Tracker built with JavaScript and  CSS

A simple single-page web app I built to help traders track forex trades and calculate stats without using spreadsheet templates.

 What it does
- Log trades with entry prices, stop losses, and take profit targets.
- Log market draws when no trade was taken.
- Automatically calculates win rates, total pips, and win/loss totals.
- Filter trade history by date (7 days, 30 days, or custom dates).
- Saves all your trade data directly in your browser.

 Tech stack
- HTML5 & CSS3 (built with custom CSS, no frameworks)
- JavaScript (ES6+)
- Browser LocalStorage
